# 数学建模竞赛论文全自动评审 Skill

> 面向国赛/美赛/华中杯等数学建模竞赛，对参赛论文+赛题+支撑材料进行六维度系统性评审，输出综合得分+维度评分+检查点明细+整改建议。

## 核心能力

| 能力 | 说明 |
|------|------|
| **六维度+进阶评审** | AI 合规(15%) + 数据真实性(15%) + 建模逻辑(25%) + 结果合理性(20%) + 写作规范(15%) + 排版支撑(10%) |
| **24+4 检查点** | 24 个基础检查点 + 4 个国奖进阶检查点，分合格/存在问题/严重问题三档 |
| **双重评估** | 省奖层次（六维度）→ 国奖层次（进阶），基础得分 ≥75 自动触发 |
| **综合评分** | 按权重计算综合得分，输出奖项潜力评估（国一/国二/省一/省二/省三/参与奖） |
| **整改建议** | 按优先级给出具体问题位置 + 整改方案，可操作、可落地 |
| **对标国赛** | 评分标准与国赛四大标准（假设/建模/结果/文字）对齐 |

## 触发词

`评审论文` `论文评审` `自查论文` `数模评审` `检查论文问题` `论文打分` `数模自查` `国赛评审`

## 使用示例

```
评审论文 → 自动激活 → 六维度评审 → 得分≥75触发国奖进阶 → 输出双重潜力评估
自查论文 → 进入自查模式，按清单逐项检查
[$mathmodel-review] 评审这份论文 → 显式调用
```

## 输出格式

评审报告含以下板块：
- **综合评分卡片**（得分/合格率/检查点统计）
- **国奖进阶评审**（国奖综合得分/等级判定/四检查点标准达标情况）
- **维度评分总表**（7维度×4检查点，含权重得分）
- **严重问题清单**（位置+整改建议，需立即修复）
- **存在问题清单**（位置+整改建议，建议修复）
- **亮点与加分项**
- **总体评价**（省奖/国奖双重潜力判断 + 四大标准细分估算）

## 安装

将整个 `mathmodel-review/` 目录复制到 BitFun 的 skills 目录下：

```
%USERPROFILE%\.agents\skills\mathmodel-review\
```

重启 BitFun 后即可通过触发词激活。
