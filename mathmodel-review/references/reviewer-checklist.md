# 数模评审检查清单（评委视角）

## 30 秒快速自检（提交前必做）

- [ ] PDF 能正常打开，中文字体显示正常
- [ ] 页码连续，无空白页/缺页
- [ ] 摘要包含关键结果数字
- [ ] 所有子问题都有对应章节
- [ ] 参考文献可在知网/谷歌学术检索到
- [ ] 支撑材料代码路径为相对路径
- [ ] 图表编号连续，正文中有引用
- [ ] AI 声明已包含在论文中

## 深度检查清单

### AI 合规
- [ ] AI 声明位置：论文正文末尾或附录前
- [ ] AI 声明内容：使用了什么 AI 工具、用于什么任务、人工审查情况
- [ ] 核心建模部分（公式推导、机理分析）有明显的人类思考痕迹
- [ ] 未出现"众所周知"、"值得注意的是"、"不难发现"等 AI 高频套话

### 数据真实性
- [ ] 所有数据可追溯至赛题附件
- [ ] 无"根据相关研究"等模糊引用
- [ ] 图表数据来源明确标注
- [ ] 无凭空捏造的统计数据

### 建模逻辑
- [ ] 假设与题面约束不矛盾
- [ ] 符号首次出现时有定义
- [ ] 公式推导无跳跃
- [ ] 模型假设有合理性说明

### 结果合理性
- [ ] 结果数量级合理
- [ ] 有至少一个敏感性分析
- [ ] 关键参数有取值依据
- [ ] 结果与常识/直觉不冲突

### 写作规范
- [ ] 摘要无公式、无图表、无引用
- [ ] 章节顺序：重述→假设→符号→建模→求解→结果→评价
- [ ] 参考文献格式统一
- [ ] 正文中引用与参考文献列表一一对应

### 支撑材料
- [ ] 代码可运行（相对路径）
- [ ] 结果文件与论文数据一致
- [ ] 有运行说明（RUN.md）
- [ ] 代码有注释和参数说明
